CanisCoach

Model:


User:
    Represents single user account in the system.
    
DB Fields in USERS table:
    - usr_id (required) - user id in the system, assigned automatically upon account creation
      Must be unique.
    - usr_email (required) - email addres used for login, chosen during registration
      Must be unique.
    - usr_password_hash (required) - hashed version of the user password, generated by the application during registration.
    - usr_join_date (required) - date of account creation. Assigned automatically upon account creation.


Dog:
    Represents single dog linked to a user.

DB Fields in DOGS table:
    - dog_id (required) - dog id in the system, assigned automatically upon creating dog profile.
      Must be unique.
    - dog_name_full (required) - dog name provided by user.
    - dog_name_short (required) - short name for dog, usually used when dog has a full pedigree name.
    - dog_usr_id (required) - id of usr who is dog owner, assigned automatically upon creating dog profile.
    - dog_breed_id (optional) - id of dog breed from BREEDS table, chosen by user upon creating dog profile.
    - dog_birth_date (optional) - dog date of birth, provided by user upon creating dog profile.
    - dog_note (optional) - text field, provied by user upon creating dog profile.
    - dog_active (required) - 1 if dog is active, 0 if dog is inactive. Assigned automatically upon dog profile creation/deletion.


Discipline:
    Represents single discipline in the world of canine sports.

DB Fields in DISCIPLINES table:
    - disc_id (required) - discipline id in the system, assigned automatically upon creation by admin.
      (for public disciplines) or user (for private disciplines). Must be unique.
    - disc_name (required) - name of discipline, provided by creator upon discipline creation.
    - disc_type (required) - type of discipline, can be 0 (public) or 1 (private).
    - disc_usr_id (optional) - if discipline is private, id of user who created it.
    - disc_active (required) - 1 if discipline is active, 0 if discipline is inactive. Assigned automatically upon discipline creation/deletion.


Workout:
    Represents single workout of a single dog.

DB Fields in WORKOUTS  table:
    - wout_id (required) - workout id in the system. Assigned automatically upon workout creation. 
      Must be uniqe.
    - wout_start_datetime (required) - time when workout starts. Provided by user upon creation.
    - wout_end_datetime (required) - time when workout ends. Calculated by system.
    - wout_duration_minutes (required) - actual time of workout in minutes. Provided by user.
    - wout_disc_id (required) - id of workout discipline. Provided by user upon creation.
    - wout_usr_id (required) - id of user who created workout. Assigned automatically upon workout creation. 
    - wout_dog_id (required) - id of participating dog. Provided by user upon creation.
    - wout_focus (optional) - text field, provided by user upon creation.
    - wout_status (required) - 0 for planned, 1 for completed, 2 for cancelled. Assigned automatically upon workout creation/completion/cancellation.
    - wout_score (optional) - result of this workout, provided by user upon completion.
    - wout_note (optional) - text field, provided by user upon completion/cancellation.
    - wout_creation_date (required) - workout creation date, assigned automatically upon workout creation
    - wout_wgroup_id (optional) - id of workout group, if shared between multiple dogs. Assigned automatically upon workout creation.
    - wout_active (required) - 1 if workout is active, 0 if workout is inactive. Assigned automatically upon workout creation/deletion.


Workout_group:
    Represents one workout form submission that created one or more workout records.

DB Fields in WORKOUT_GROUPS table:
    - wgroup_id (required) - workout group id in the system. Assigned automatically upon workout creation.
    - wgroup_usr_id (required) - id of user who created workout. Assigned automatically upon workout creation.
    - wgroup_creation_date (required) - date of creation of workout group. Assigned automatically upon workout creation.


Breed:
    Represents a single dog breed.

Db Fields in BREEDS table:
    - breed_id (required) - breed id in the system. Assigned automatically upon breed creation. 
    - breed_name (required) - breed name. Assigned automatically upon breed creation.


Rules:
    1. wout_dog_id must point to dog that belongs to wout_usr_id
    2. wout_disc_id must point to public discipline, or private discipline that belongs to
       wout_usr_id
    3. wout_wgroup_id must point to wgroup_id that belongs to wout_usr_id
    4. Inactive dogs and disciplines are not available for new workouts, but remain visible in old workout history.
    5. Inactive workouts are hidden from default views and statistics.
